## Motivation

This repository was created to with the main intention of sharing the license templates that **I**, **von Schappler** (either as a [person](https://github.com/code-with-von) or as a [professional](https://github.com/vonschappler)) created and started making use on everything I create.

Before 2026, I never cared about this aspect, until the day I noticed people were taking credits of work I had done, just by making small changes over that, and so **I saw** the need to at least ensure that I can do something to help me into keeping part of the **authorial** / **copyright** of the original work that was used by **third parties**.

People, when using something that they can find at the **internet**, needs to understand that **it's not because it's there that they are allowed to use it** without giving the **rightful** credits to the one(s) who created anything they are using.

And that is why **Licenses** exist. So with this in mind, **I had created this set of files** considering the use-cases I deal in my day-by-day life and I am sharing[^1] them for those who also need to deal with similar situations.

## Submitting an Issues and Other requests for this project

This project has custom forms for each different type of issue we are currently able to work at.

To submit an issue, click on the **Issues** button above. That will open our **Issues page** where a green button **New issue** will be available. Click on it and select the appropriate option.

### Requesting new license templates

If you like this concept and there is something you think it's missing, submit your request by using the option  **A template I would like to use is not provided** after reaching the **New issue** page.

> [!note]
> After submission, rest assured your request will be fulfilled based on **my free time** and **possible needs / use-cases** where I see it fit.

---

### Reporting grammar problems

If you find any grammar problems in the templates provided, please submit a request selecting the **Grammar, spelling and language improvements** option in our **New issue** page.

> [!note]
> The requests will be checked, evaluated and fixed if/when needed, but after submission, all process of fixing will be based on **my free time**.
